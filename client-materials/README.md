## 内容使用规则

1. 产品中心只使用 `product-catalog-from-word.md` 中出现的产品名称、规格和子项。
2. 公司简介中的四类产品方向作为企业业务说明，不自行拆成具体型号或性能参数。
3. 未提供的型号、功率、电压、适配品牌、应用绑定、性能卖点、维修内容、交付标准和合作流程统一不作推测。
4. 没有明细的产品只显示“详细内容待补充”。
